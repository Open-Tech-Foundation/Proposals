A collection of practical technology and design proposals intended to improve everyday user experience while preserving compatibility, accessibility, and implementation feasibility.

## Purpose

This repository is for structured proposals that are:

- Practical and implementation-oriented
- Written in clear standards-style language
- Compatible with existing systems where possible
- Open to discussion, revision, and community feedback

## Proposal Statuses

| Status | Meaning |
|--------|---------|
| Draft | Initial proposal open for discussion |
| Review | Under active feedback and revision |
| Accepted | Considered stable by maintainers |
| Rejected | Not currently recommended |
| Superseded | Replaced by a newer proposal |

## Contributing

Suggestions, corrections, and alternative proposals are welcome. When adding a new proposal, use a numbered folder under `proposals/` and include a clear `README.md`.
